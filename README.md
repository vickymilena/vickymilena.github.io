# Vicky Ruiz — sitio web profesional

Primera versión del sitio personal de Vicky Ruiz: docencia, investigación y consultoría.

## Publicación gratuita en GitHub Pages

1. En GitHub, crear un repositorio público llamado `vicky-ruiz-web` (sin reemplazar ningún repositorio anterior).
2. Abrir el nuevo repositorio y elegir **Add file → Upload files**.
3. Subir directamente los archivos `index.html` y `favicon.svg` (no subir solamente la carpeta que los contiene). Puedes agregar este README también.
4. Confirmar los archivos mediante **Commit changes**.
5. Ir a **Settings → Pages**; en **Build and deployment**, elegir **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guardar.
6. La dirección esperada será `https://vickymilena.github.io/vicky-ruiz-web/` una vez publicada por GitHub. Comprueba la URL en Settings → Pages.

## Previsualización

Abrir `index.html` en un navegador. El diseño funciona sin instalar herramientas. Las fuentes externas requieren conexión a internet; hay fuentes alternativas.

## Datos e imágenes

El sitio usa un monograma en vez de una fotografía personal. No contiene un formulario ni publica datos de contacto privados.

Antes de utilizarlo como portafolio definitivo, revisar títulos académicos, estado de investigaciones y servicios. Para editar textos o enlaces, abrir `index.html` en un editor de texto.

## Archivos

- `index.html`: diseño, contenido, estilos y menú móvil.
- `favicon.svg`: ícono de la pestaña.
- `README.md`: instrucciones.
